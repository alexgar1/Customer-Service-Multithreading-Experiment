# Customer-Service-Multithreading-Experiment

This C program is an exercise in multithreading simulating a airplane with business class and economy customers with complaints and clerks who can settle them. The business class complaints take priority over the economy complaints and clerks can only handle one complaint at a time but can work simultaneously. The object of this exercise is use multithreading to find the most efficient way of solving all complaints



 The check-in system includes 2 queues and 5 clerks. One queue for economy class and the other for business class. The customers in the business class have a higher priority than the customers in the economy class. This code demonstrates my understanding of multithreading, mutexes and condvars.
